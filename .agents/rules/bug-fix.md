# Bug Fix — Universal Always-On Rule

**MANDATORY when the user reports a bug, issue, regression, or asks to fix something broken.**

## Read before coding

1. **`AGENT_BUG_FIX_RULEBOOK.md`** (repo root) — universal workflow + guardrails (any project)
2. **Project `AGENTS.md`** — this repo’s contracts and ownership
3. **Project bug register** (if exists) — e.g. `SMALL_BUG_FIX_PLAN.md` here

## Universal quick rules

- **Minimal diff** — fix root cause; no bundled refactors
- **Project docs second** — rulebook is generic; `AGENTS.md` is binding for *this* repo
- **Classify** — open vs fixed vs regression vs new
- **Verify** — reproduce fix; smoke adjacent flows
- **Document** — update bug register; don’t leave silent fixes

Full process: **`AGENT_BUG_FIX_RULEBOOK.md`**
